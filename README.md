
# 🎮 Number Guessing Game

## 📌 Project Description

The Number Guessing Game is a simple and interactive web-based game developed using HTML, CSS, and JavaScript.

In this game, the computer randomly selects a number between 1 and 100. The player must guess the correct number.

After each guess, the game provides hints such as "Too High" or "Too Low" until the player finds the correct number.

It is a beginner-friendly project designed to improve JavaScript programming and logical thinking skills.

## ⚙️ Installation and Setup

Create a folder named Number-Guessing-Game.

Open the project folder using Visual Studio Code.

### Step 3: Create Files

Create the following four files:

- index.html
- style.css
- script.js
- README.md

### Step 4: Add Source Code

Paste the respective HTML, CSS, and JavaScript code into the files.

### Step 5: Run the Application

1. Open index.html.
2. Right-click on the file.
3. Select Open with Live Server.
4. The game will open in your web browser.

## 🎮 How to Play

1. Open the Number Guessing Game.
2. Read the game instructions.
3. Enter a number between 1 and 100.
4. Click the Check Guess button.
5. Read the hint displayed on the screen.
6. If the guess is too low, enter a higher number.
7. If the guess is too high, enter a lower number.
8. Continue until you guess correctly.
9. Click Restart Game to play again.
